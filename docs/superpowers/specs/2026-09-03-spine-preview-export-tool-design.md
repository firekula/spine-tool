# Spine 动画预览与图集子图导出工具设计

## 1. 项目目标

构建一个纯浏览器运行的中文工具，用于导入 Spine 导出文件，预览骨骼动画、切换动画和皮肤、控制插槽显示，并将 Atlas 中的全部 Region 恢复成原始尺寸 PNG 后打包为 ZIP。

工具同时提供：

- 可部署到静态服务器的网站版本；
- 不依赖网络、解压后即可使用的离线完整包；
- 完整源代码。

所有用户文件仅在浏览器本地读取和处理，不上传服务器。

## 2. 支持范围

### 2.1 Spine 版本

第一版明确支持：

- Spine 3.8
- Spine 4.0
- Spine 4.1
- Spine 4.2

分别内置对应版本的 Spine WebGL Runtime，并通过统一的版本适配层调用。JSON 从 `skeleton.spine` 读取版本，SKEL 从二进制头部读取版本。自动识别失败或版本信息不完整时，允许用户手动选择 Runtime 并重新加载。

3.7、4.3 或其他范围外版本显示明确警告，不使用错误版本静默加载，也不承诺兼容。

### 2.2 输入文件

每次导入包含：

- 一个 `.atlas` 文件；
- 一个 `.json` 或 `.skel` 骨骼文件；
- 一张或多张 `.png` 纹理页。

工具解析 Atlas 声明的纹理页并按文件名匹配 PNG。缺少纹理、重复文件名或名称不一致时，列出具体问题和期望文件名。

### 2.3 Atlas 格式

解析层兼容 Spine 3.8 至 4.2 常见的 Atlas 字段写法，包括：

- 旧版 `xy`、`size`、`orig`、`offset`、`rotate`；
- 新版 `bounds`、`offsets` 和角度旋转值；
- 单页和多页纹理；
- Region 名称中的目录路径；
- 裁剪区域、透明边距和旋转打包。

## 3. 技术方案

### 3.1 总体架构

采用纯静态前端架构，不需要后端。主要模块为：

1. 文件导入与匹配模块：读取本地文件，校验组成并建立资源映射。
2. 版本检测模块：识别 JSON/SKEL 版本并选择适配器。
3. Runtime 适配层：用统一接口封装 Spine 3.8、4.0、4.1、4.2 Runtime 的差异。
4. 动画预览模块：管理 WebGL 渲染、播放状态、视图和资源释放。
5. 动画、皮肤与插槽控制模块：读取骨骼元数据并响应界面操作。
6. Atlas 解析与子图恢复模块：独立解析 Atlas，裁切、反旋转、补回透明边距并恢复导出倍率。
7. ZIP 导出模块：生成全部 PNG 和导出报告。

Runtime 与图集导出相互隔离：即使某个骨骼文件无法被 Runtime 播放，只要 Atlas 和 PNG 有效，用户仍可查看问题并尝试导出图集子图。

### 3.2 多版本 Runtime

各版本 Runtime 独立打包在不同模块作用域内，避免全局命名冲突。统一适配接口至少包含：

- 加载骨骼、Atlas 和纹理；
- 创建与销毁预览实例；
- 获取动画、皮肤和插槽列表；
- 设置动画、循环、速度和播放位置；
- 设置单一皮肤或组合皮肤；
- 设置插槽可见性；
- 更新画面、调整视图和释放 GPU 资源。

组合皮肤通过创建临时组合 Skin 实现。隐藏插槽在每帧动画状态应用后统一处理，避免动画关键帧重新显示已隐藏插槽。

## 4. 用户界面

页面以桌面工具为主，分为五个区域：

- 顶部工具栏：文件导入、重新导入、版本识别结果、运行状态和错误入口；
- 左侧控制栏：动画、皮肤、插槽三个页签；
- 中央预览区：WebGL 动画画布；
- 底部播放栏：播放/暂停、循环、速度、当前时间、总时长和时间拖动；
- 右侧导出栏：Region 列表、倍率分析、手动倍率和导出按钮。

### 4.1 预览交互

- 导入成功后自动选择首个动画并循环播放；
- 支持搜索和切换动画；
- 支持播放、暂停、循环、0.25 至 2 倍速度及进度拖动；
- 支持鼠标滚轮缩放、拖动画面、重置视角和自动适配；
- 支持透明网格、浅色、深色背景切换；
- 切换动画时保留播放速度；
- 连续导入时释放之前的纹理、WebGL 和对象 URL。

### 4.2 皮肤控制

- 默认提供单选皮肤模式；
- 提供组合皮肤模式，可同时勾选多个皮肤；
- 切换皮肤后恢复 Setup Pose 并重新应用当前动画；
- 支持皮肤名称搜索。

### 4.3 插槽控制

- 每个插槽提供独立显示复选框；
- 支持按名称搜索、全选、全不选和恢复默认；
- 插槽隐藏不修改源文件，不影响动画播放状态；
- 切换动画或皮肤后继续保持用户设置的隐藏状态。

## 5. 子图恢复与倍率推算

### 5.1 Region 恢复流程

每个 Atlas Region 按以下顺序处理：

1. 在其所属纹理页中按 Atlas 坐标裁切打包矩形；
2. 按 `rotate` 信息反向旋转，恢复正确方向；
3. 根据 `offset/orig` 或 `offsets` 将有效像素放回透明的原始画布；
4. 应用最终恢复倍率；
5. 输出带透明通道的 PNG。

坐标换算必须分别处理旧版和新版 Atlas 字段，校验裁切范围不得超出纹理边界。

### 5.2 导出倍率推算

部分 Spine 导出不会在 Atlas 中直接记录 50% 等打包比例，因此采用“自动推算 + 手动校正”：

- 优先使用 Atlas 中可直接证明比例的字段；
- 对 Region 附件，比较骨骼附件尺寸与 Atlas 原始尺寸；
- 汇总多个有效附件的候选倍率，排除明显离群值；
- 将结果匹配到常见导出比例：25%、50%、75%、100%、150%、200%；
- 显示推算依据、样本数量和高/中/低置信度；
- 用户可设置全局倍率，也可对单个异常 Region 覆盖倍率；
- 网格附件或无可比较尺寸的 Region 不用于生成高置信度结论。

无法可靠推算时默认保持 1 倍，并在导出前醒目标记，不静默放大。

放大时使用浏览器高质量图像平滑；恢复目标是尺寸与透明边距正确，不虚构原始纹理中已经丢失的像素细节。

### 5.3 ZIP 内容

“导出全部 ZIP”生成：

- 所有恢复后的 PNG；
- `export-report.json` 导出报告。

Region 名称中的目录结构在 ZIP 中保留，例如 `body/head.png`。对非法路径、路径穿越片段和重名进行安全清理与稳定重命名。

导出报告为每张图片记录：

- Region 名称与来源纹理页；
- Atlas 裁切区域和旋转信息；
- 原始尺寸与透明边距；
- 自动推算倍率、用户覆盖倍率和最终倍率；
- 推算依据、置信度和警告；
- 最终输出尺寸及 ZIP 路径。

## 6. 错误处理

所有界面提示使用中文，并区分阻断错误与可继续警告。

阻断错误包括：

- 缺少 Atlas、骨骼文件或必要纹理页；
- JSON 损坏或 SKEL 无法解析；
- Spine Runtime 无法加载该数据；
- 浏览器不支持 WebGL；
- ZIP 生成失败。

可继续警告包括：

- Spine 版本超出明确支持范围；
- 存在未使用的 PNG；
- 个别 Region 超出纹理边界；
- 个别 Region 无法判断恢复倍率；
- 文件过大，可能造成浏览器内存不足。

错误信息需包含问题对象、原因和用户可以采取的下一步操作。

## 7. 隐私、性能与限制

- 文件只通过浏览器 File API 读取，不发送网络请求上传用户资源；
- 网站版仅加载应用自身静态资源；离线版不请求 CDN；
- 大文件处理期间显示进度，避免重复点击；
- PNG 恢复按顺序或受控并发处理，及时释放临时 Canvas 和对象 URL；
- 浏览器无法恢复因 50% 导出而永久丢失的像素细节，只能恢复逻辑尺寸并进行高质量插值；
- 使用 Spine Runtime 的构建和分发遵循 Esoteric Software 对 Spine Runtime 的授权条款，页面中保留所需版权与许可说明。

## 8. 验收标准

### 8.1 文件与版本

- Spine 3.8、4.0、4.1、4.2 的 JSON 和 SKEL 示例均能由正确适配器加载；
- 单页、多页 Atlas 均能正确匹配纹理；
- 缺失文件、错误版本和损坏数据均提供中文可操作错误。

### 8.2 预览

- 动画可切换、循环、暂停、变速和拖动时间；
- 单一皮肤和组合皮肤能够正确切换；
- 插槽能逐个隐藏、批量切换并跨动画保持状态；
- 预览能缩放、平移、自动适配和切换背景；
- 连续导入不同项目不会继续显示旧资源。

### 8.3 导出

- 单页和多页 Atlas 的全部有效 Region 均进入 ZIP；
- 旋转 Region 的方向正确；
- 裁剪 Region 恢复到带透明边距的原始画布；
- Region 嵌套路径和重名得到稳定、安全处理；
- 50%、100%、200% 等测试数据的逻辑尺寸恢复正确；
- 低置信度倍率在导出前和报告中都有明确提示；
- `export-report.json` 与实际 PNG 一一对应。

### 8.4 交付形态

- 静态网站部署后可直接使用；
- 离线完整包断网后仍能打开并完成导入、预览与 ZIP 导出；
- 源代码可重复构建出网站版和离线版。

## 9. 明确不包含的范围

第一版不包含：

- 编辑或保存 Spine 骨骼数据；
- 将旧版 Spine 数据转换成新版数据；
- 导出 GIF、视频或序列帧；
- 修改附件、网格、权重或动画关键帧；
- 在服务器保存用户项目；
- 恢复缩小导出前已经丢失的真实像素细节。
